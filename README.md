# HR Analytics Dashboard | Excel

## Project Overview
This is a beginner-level HR Analytics portfolio project created using Microsoft Excel. It explores a fictional employee dataset to identify patterns in department-wise employee distribution, salary, and attrition.

## Objectives
- Analyse employee distribution across departments.
- Compare average monthly salaries.
- Understand employee attrition.
- Present key findings through an Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis and Visualisation

## Key Insights
- Total employees analysed: 30
- Employees who left: 9
- Overall attrition rate: 30%
- Highest average monthly salary: IT department

## Dashboard Features
- Total Employees KPI
- Attrition Rate KPI
- Employees Left KPI
- Highest Paid Department KPI
- Average Monthly Salary by Department chart
- Employee Attrition pie chart

## Project Files
- `HR_Analytics_Mini_Project.xlsx` – Excel workbook containing the analysis and dashboard.
- `hr_analytics_mini_dataset.csv` – Fictional employee dataset.

## Note
This project uses fictional data created for learning and portfolio demonstration. It does not contain real employee information.
