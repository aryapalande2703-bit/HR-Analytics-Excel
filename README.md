# HR Analytics Mini-Project

## Project Overview
This is a beginner-level HR Analytics project created using Microsoft Excel. The project analyses a sample dataset of 30 fictional employees across five departments.

## Tools Used
- Microsoft Excel
- PivotTables
- Data Visualization

## Project Objectives
- Count employees in each department.
- Compare average monthly salaries across departments.
- Analyse employee attrition.
- Present findings using a column chart.

## Key Findings
- Total employees analysed: 30
- IT and Sales have the highest employee count, with 7 employees each.
- IT has the highest average monthly salary at ₹57,000.
- HR has the lowest average monthly salary at ₹37,400.
- 9 employees have attrition marked as Yes, representing 30% of the sample.

## Files Included
- `HR_Analytics_Mini_Project.xlsx` — Excel workbook containing PivotTables and a chart.
- `hr_analytics_mini_dataset.csv` — Original sample dataset.

## Note
This project uses fictional data for educational and portfolio purposes only.
